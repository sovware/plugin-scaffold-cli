# Plugin Scaffold CLI

Interactive personalization command for [WP Plugin Scaffold](https://github.com/syedgalib/wp-plugin-scaffold).

Install it in the scaffold with Composer, then run `composer plugin:setup`. The command asks for a plugin name, optional description, optional Plugin URI, Author, and Author URI, a text domain, and a PHP namespace. Leave any of the three new optional fields blank to keep its existing value. It renames the main PHP file to match the text domain and updates the scaffold's source files and build configuration in place.
